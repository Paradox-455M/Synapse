Privacy Policy

Last updated: March 2026

Synapse does not collect, transmit, or share any personal data with any external server. Everything stays in your browser.

What Synapse stores locally

The following data is stored in chrome.storage.local on your device only:

  • Your active brain selection, mode (auto/manual), and enabled state
  • Custom brains you create in Brain Studio
  • Memory facts you write per brain (e.g. "Using Go 1.25", "Prefers REST over GraphQL")
  • Activation counts and refusal counts (local analytics — never sent anywhere)
  • Conversation locks (which brain is active per conversation ID)
  • An onboarded flag so the welcome screen only shows once

What Synapse syncs across your devices

The following data is stored in chrome.storage.sync, which Chrome syncs across your signed-in Chrome profiles. This data never leaves Google's infrastructure and is not accessible to Synapse:

  • Settings: active brain, mode, enabled state
  • Custom brains you create

How the prompt injection works

Synapse intercepts outgoing fetch requests to ChatGPT, Claude.ai, Gemini, and Perplexity inside your browser and prepends a system prompt from your selected brain. This modification happens entirely client-side. The modified prompt goes directly to the AI platform you are using — not to any Synapse server.

Synapse has no backend, no servers, and no accounts.

What Synapse does not do

  • Does not transmit your prompts or conversation content to any Synapse server
  • Does not require an account or any login
  • Does not use cookies, tracking pixels, or analytics services
  • Does not share data with any third party
  • Does not read your conversation history (only the outgoing request being sent)

Permissions explained

  • storage — to save your brain settings and memory facts locally
  • scripting — to inject the brain context script when CSP blocks the default method
  • activeTab — to read the current tab URL for conversation ID detection
  • tabs — to open links (privacy policy, bug reports) in a new tab from the popup
  • host_permissions (chatgpt.com, claude.ai, gemini.google.com, perplexity.ai) — to intercept outgoing API requests and inject brain context before they are sent
